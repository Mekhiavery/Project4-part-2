# Job Market Data Aggregation Project

## Overview
This project collects job postings from multiple job platforms such as LinkedIn, Indeed, and CareerBuilder using Python scripts.

The goal is to gather job market data that can later be analyzed to identify hiring trends and demand for specific skills.

## Technologies
- Python
- Web scraping
- Data processing
- GitHub

## Files
Careerbuilder.py – Collects job data from CareerBuilder  
Linkedin.py – Collects job listings from LinkedIn  
indeed2.py – Collects job data from Indeed  
JobDB.py – Handles database storage
